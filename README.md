# 🐦 Flappy Bird — Core Java

> A simple Flappy Bird-inspired game developed using Java Swing and AWT to practice programming, game logic, graphics, keyboard input, collision detection, and basic game physics.

## 🎮 About the Project

This project is a simple 2D Flappy Bird-style game created using **Core Java** without using a dedicated game engine.

The player controls a bird and must navigate through randomly generated pipe obstacles while avoiding collisions.

The project was created as a practical Java project to apply programming concepts to an interactive application.

## ✨ Features

* 🐦 Bird movement with gravity
* ⬆️ Spacebar-controlled flapping
* 🟩 Three moving pipe obstacles
* 🎲 Randomized pipe heights
* 💥 Collision detection
* 🏆 Score tracking
* 🔄 Game restart functionality
* 🎨 Custom bird sprite
* 🔄 Bird rotation based on movement velocity
* 💀 Game-over screen

## 🛠️ Technologies Used

| Technology          | Purpose                   |
| ------------------- | ------------------------- |
| ☕ Java              | Core programming language |
| 🖥️ Java Swing      | Window and UI             |
| 🎨 AWT / Graphics2D | Game rendering            |
| 🖼️ BufferedImage   | Loading the bird sprite   |
| ⏱️ Swing Timer      | Game loop                 |
| 🎲 Random           | Random pipe generation    |

## 🎮 Controls

| Key     | Action                      |
| ------- | --------------------------- |
| `SPACE` | Flap / move the bird upward |
| `S`     | Restart after Game Over     |

## ▶️ How to Run

### 1. Compile the project

```bash
javac FlappyBird.java
```

### 2. Run the game

```bash
java FlappyBirdGraphics
```

Make sure `Bird.png` is in the same directory as the Java file.
